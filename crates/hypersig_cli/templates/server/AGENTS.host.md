The server runs in a container that the `Dockerfile` builds, on a host such as Fly.io, Cloud Run, or Render, and `cargo run` serves it at http://localhost:3000, or at the port in `PORT` where that is set. A host that runs more than one container runs one process in each, and a value in memory or a `tokio::sync::broadcast` channel reaches only its own process. Data that has to outlive the process or reach every container goes in a database, and a change reaches the other processes as [Updates with more than one process](https://imaimai17468.github.io/hypersig/learn/database/#updates-with-more-than-one-process) shows.
